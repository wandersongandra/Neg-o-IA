## Se não funcionar:

Verifique os logs do Terminal 1 (Backend) para mensagens de erro.

Erros comuns:
- "ModuleNotFoundError" → Execute: `pip install -e .`
- "Port 8000 already in use" → Feche a porta: `lsof -i :8000` ou `netstat -ano | findstr :8000`
- "Database connection error" → Infraestrutura está pronta, erro de conexão momentâneo
